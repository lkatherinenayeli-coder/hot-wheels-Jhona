REGALO HOT WHEELS — INSTRUCCIONES

1. El archivo principal es index.html.
2. Abre index.html en tu navegador para probar la página.
3. Para compartirla mediante un link público, sube index.html a un servicio de alojamiento estático (por ejemplo, GitHub Pages, Netlify o similar).
4. No necesita servidor, base de datos ni instalación: todo está dentro del HTML.
5. Puedes editar el mensaje directamente en index.html buscando el texto que aparece en la tarjeta.

La página está diseñada para celular y funciona sin imágenes externas.
